电压控制原理

任何模块的输出都能控制任何模块 —— 合成器的第一性原理

相关

特雷门琴音轮风琴电吉他马特诺琴泛音列音高

前面几页的电子乐器，每一件都是一个「完成的设计」——形状在发明时就定了。

这一页写的是它们的反面：一台发不出声的乐器——直到你亲手把它连起来。

「模块只是盒子，默认没有任何东西把它们连起来。必须先 patch（接线），合成器才能发声。」

⭐⭐ 本页写电压控制原理——模拟合成器小类的理论基石。主线一句话：任何模块的输出都能控制任何模块。

分类归属
HS 分类电鸣（Electrophone · 电子振荡 + 电压控制）· 模块化（可无限重组）· 复音视型号
两大原则⭐⭐ 「真正的合成器」自 1960 年代起实现两大原则：减法合成 + 电压控制——「Ondes Martenot · Mellotron · Hammond 音色相对有限，通常不被认为是 synthesizer」
发明⭐⭐ Bob Moog 与 Don Buchla 于 1960 年代初各自独立发展——Moog 造出「第一台商业化合成器」
八音对照八音之外——它甚至不是「一件」乐器，是一套搭建规则

⭐⭐ 主线：任何模块的输出都能控制任何模块

「电压控制方法允许任何模块的输出被接线到任何其他模块的输入——一个极其强大且通用的系统。」

⭐⭐ 在这之前，每件乐器的「控制方式」都是固定的：弦由手指控、管由气流控、特雷门由手势控——控制手段与发声体焊死在一起。

⭐⭐ 电压控制把「控制」本身抽出来变成一种信号—— 振荡器的音高、滤波器的截止点、放大器的增益，全部是「电压」的函数。 于是「控制」可以像接线一样被重排。

⭐⭐ 三大件：VCO · VCF · VCA

减法合成的经典信号链，三个压控模块：

⭐ VCO 压控振荡器⭐ VCF 压控滤波器⭐ VCA 压控放大器
管什么音高（产生富谐波波形）音色（截止频率，选择性移除谐波）音量（增益）
被谁控键盘 CV + 其他包络/LFO/任何 CV包络（ADSR）
一句话「声源」「把富波形做减法」「把音的生灭塑形」

⭐⭐ VCO 的 1V/octave 标准：「电压升 1 伏 = 音高升一个八度」； ⭐⭐ 「Moog 从一开始就与音乐家合作，所以他的振荡器内建了指数转换器—— 线性键盘电压进来，振荡器频率每伏倍增」。

⭐⭐ 还有一条容易被忽略的：「CV 不是绝对参数而是相对参数—— 某个 CV 值（如 +1.0V）不对应任何绝对音高」； VCO 的最终音高 = 外部 CV + 调音旋钮 + 八度开关 + 其他 CV 输入的总和。 ⭐ 对照管风琴的音栓（Hammond 拉杆）：那里的音高是「选出来的」；这里的音高是「加出来的」。

⭐⭐ ADSR：一个音的「一生」

包络发生器「由触发或门信号激活后，产生一个从零伏升到最大电压、再回到零伏的信号」。

⭐⭐ 四个阶段对应一个音的一生：

阶段发生什么
⭐ A — Attack 起音键按下 → 音量从零爬到峰值（多快爬上去）
⭐ D — Decay 衰减爬到峰值后往回落（回落到哪）
⭐ S — Sustain 延持按住不放时停在哪（按住时的水位）
⭐ R — Release 释音手抬起来后多久归零（收尾多快）

⭐⭐ 「它最常用于控制 VCA——塑造一个音的动态（并保证它最终会停止！）」—— ADSR 是一件乐器对「时间」的第一次完整建模。

⭐ GATE 信号：「对应键盘上按下一颗键——高于约 +3V 视为『高』（+5V/+8V 都行），低于 1V 视为『低』」。

⭐⭐ LFO：不发声的振荡器

「LFO 设计为在极低频率（从最低可听频约 20 Hz 到远低于 1 Hz）产生精确波形。」

⭐⭐ 它自己不出声——但一个 LFO 有三种用途：

喂给效果像什么
⭐ VCO颤音 vibrato「歌剧演员的声音」
⭐ VCA震音 tremolo音量反复增减
⭐ VCF滤波扫掠 sweep「让更多频率通过又减少，声音不停变化」

⭐⭐ 「它自己的声音你听不见，但每个音的活气都是它给的。」

⭐⭐ 三类信号：模块化的全部纪律

「Audio 信号（VCO/NOISE 产生，典型 10Vpp 即 -5V 到 +5V）· 控制电压（LFO 典型 -2.5 至 +2.5V；ADSR 0 至 +8V）· 触发/门/时钟（矩形波，典型 0/+5V，上升沿触发）。」

⭐⭐ 把「声音」「控制」「时刻」分成三种不同的线—— 模块化系统的全部纪律就在这根分线上： 声音线不能接进触发口，触发口不该喂音频——每根线都知道自己是什么。

⭐⭐ Patch：有针无线，真难寻一个音

「模块只是盒子，默认没有任何东西把它们连起来。必须先 patch（接线），合成器才能发声。」

⭐⭐ 「patches 让这些东西特别」：「你可以把任何模块喂给任何模块——产生各种古怪迷人的声音」； ⭐⭐ 「把 patch 从合成器上拔掉，你就剩下一块白布。你带回来的一切都只是习惯，不在设备里——一块完全开放的画布。」

⭐⭐ 但代价也在这里：

「Doors 键盘手 Ray Manzarek 描述了乐队把喜欢的效果与配置复原时的挫败—— 完美的声音永远无法一模一样地复现——『模拟合成的美与挫败』。」

⭐⭐ 《千祈莫拆针离线》——这首民歌的标题，就是每一位模块合成器玩家的第一戒律。

⭐⭐ 其他核心模块（速览）

Sub-oscillator 副振荡器——「加一个低一两八度的振荡器，把声音变厚」； Ring modulator 环形调制器——「输出是两输入频率的和与差——通常产生西方音阶『之间』的频率，最常用于金属声」； Glide/Slew limiter——「把一个音滑到另一个音——⭐ 键盘手天然做不到这个效果，因为每颗键都是分离的半音，这个模块给他们滑音能力」（对照马特诺的丝带：一个补键盘的短板，一个补人手的短板）； Sample & hold——「采样输入并保持，直到下一个触发——输入噪声就是随机音符序列」。

⭐⭐ 1V/oct：一场标准化的胜选

「缺点之一是标准化——不同厂商用不同电压系统，一家公司的合成器难以接到另一家上—— 最终 1V/octave 系统胜出。」

⭐⭐ Buchla 用的是别的标准——两位发明人的分歧至今仍在 Eurorack 里（⭐ 电压标准的「方言」至今没统一）。

HS电鸣（电子振荡 + 电压控制）

在这之前，每件乐器的「怎么控制」都是天生的；电压控制之后，控制变成了可以重排的线。 ⭐⭐ 有针无线，真难寻一个音——合成器的第一课不是发声，是接线。

事实来源

  • ⭐⭐ 主线：任何模块的输出都能控制任何模块（本页最该记住的一条） —— 「电压控制方法允许任何模块的输出被接线到任何其他模块的输入——一个极其强大且通用的系统」；⭐⭐ 由 Bob Moog 与 Don Buchla 于 1960 年代初各自独立发展——「这一技术由『模拟合成器之父』Robert Moog 变成现实，造出 60 年代第一台商业化合成器」；⭐⭐ 「真正的合成器」自 1960 年代起实现两大原则：减法合成 + 电压控制——「Ondes Martenot · Mellotron · Hammond 音色相对有限，通常不被认为是 synthesizer」（⭐ 本站前面写的电子乐器「是不是合成器」的判据，就在这里）
  • ⭐⭐ VCO（压控振荡器）：1V/octave —— 「电压升高 1 伏 = 音高升高一个八度」；「电压突变 → 音高突变；电压平滑连续变化 → 滑音（portamento）」；⭐⭐ 「Moog 从一开始就与音乐家合作，所以他的振荡器内建了指数转换器——线性键盘电压进来，振荡器频率每伏倍增」；⭐⭐ 「CV 不是绝对参数而是相对参数」——「某个 CV 值（如 +1.0V）不对应任何绝对音高」：VCO 的最终音高 = 外部 CV + 调音旋钮 + 八度开关 + 其他 CV 输入的总和
  • ⭐⭐ VCF（压控滤波器）与 VCA（压控放大器） —— 「VCF 被电压控制的参数是截止频率：控制电压的量改变截止频率，从而改变 VCF 让通过的信号频率范围」；「VCA 的增益可被电压控制」；⭐⭐ 减法合成的经典信号链：「振荡器产生富谐波的波形 → 滤波器选择性地移除谐波 → 放大器塑造每个音的动态（包络）」——⭐ 「从富波形里做减法」，与加法合成（Telharmonium/Hammond）正好相反
  • ⭐⭐ ADSR 包络发生器 —— 「由触发或门信号激活后，产生一个从（通常）零伏升到最大电压、再在某段时间后回到零伏的信号」；「最常用于控制 VCA——塑造一个音的动态（并保证它最终会停止！）；也能控制 VCF 产生音色变化」；⭐⭐ 四个阶段：「Attack（起音）· Decay（衰减）· Sustain（延持）· Release（释音）——从按键、到抬指、以及之间的全部」；GATE 信号：「对应键盘上按下一颗键——A-100 内通常高于约 +3V 视为『高』（+5V/+8V/+12V 都行），低于 1V 视为『低』」
  • ⭐⭐ LFO（低频振荡器）：不发声的振荡器 —— 「设计为在极低频率（从最低可听频约 20 Hz 到远低于 1 Hz）产生精确波形」；⭐⭐ 一个 LFO 三种用途：「喂给 VCO → 颤音（vibrato，像歌剧演员的声音）· 喂给 VCA → 震音（tremolo，音量反复增减）· 喂给 VCF → 滤波扫掠（sweep，让更多频率通过又减少，声音不停变化）」—— ⭐ 「它自己的声音你听不见，但每个音的活气都是它给的」
  • ⭐⭐ 三类信号（模块化的纪律） —— 「Audio 信号（VCO/NOISE 产生，典型 10Vpp 即 -5V 到 +5V）· 控制电压（LFO 典型 -2.5 至 +2.5V；ADSR 0 至 +8V）· 触发/门/时钟（矩形波，典型 0/+5V，上升沿触发）」→ ⭐⭐ 把「声音」「控制」「时刻」分成三种不同的线——模块化系统的全部纪律就在这根分线上
  • ⭐⭐ Patch：模块只是盒子 —— 「模块只是盒子，默认没有任何东西把它们连起来。必须先 patch（接线），合成器才能发声」；⭐⭐ 「patches 让这些东西特别」：「你可以把任何模块喂给任何模块——一个模块的输出作为另一个的输入——产生各种古怪迷人的声音」；「把 patch 从合成器上拔掉，你就剩下一块白布。你带回来的一切都只是习惯，不在设备里——一块完全开放的画布」依专题类资料
  • ⭐⭐ 模组的代价（Manzarek 的挫败） —— 「Doors 键盘手 Ray Manzarek 描述了乐队把喜欢的效果与配置复原时的挫败——完美的声音永远无法一模一样地复现——『模拟合成的美与挫败』」；「模组化 Moog 的体积也是问题」依专题类资料
  • ⭐ 其他核心模块（速览） —— Sub-oscillator（副振荡器）「加一个低一两八度的振荡器，把声音变厚」· Ring modulator（环形调制器）「输出是两输入频率的和与差——通常产生西方音阶『之间』的频率，最常用于金属声」· Glide/Portamento/Slew limiter「把一个音滑到另一个音——键盘手天然做不到这个效果，因为每颗键都是分离的半音，这个模块给他们滑音能力」· Sample & hold「采样输入并保持，直到下一个触发——输入噪声就是随机音符序列」依专题类资料
  • ⭐⭐ 1V/octave 的标准化 —— 「缺点之一是标准化——这跟 CV 原则无关，而是各家实现不同：不同厂商用不同电压系统，一家公司的合成器难以接到另一家上——最终 1V/octave 系统胜出」（Buchla 用的是别的标准——两位发明人的分歧至今仍在 Eurorack 里）依专题类资料
  • 「合成器属电鸣（Electrophone · 电子振荡 + 电压控制）」依 Hornbostel–Sachs 分类
