吉他借你的嘴当滤波器 —— 电子时代最身体的效果器

八音：不适用 —— 它的“乐器”是演奏者的口腔

一根管子，把声音送进嘴里

踏板里是一只取掉号筒的喇叭单元。声音经气密接头进入塑料管，管口送到嘴边。管子越长，高频丢得越多，声音越像人压着嗓子说话。嘴的形状会改变谐波含量，和说话时改变声带谐波是同一个道理。麦克风收到的，是被嘴塑过形的乐器声。演奏者始终不发声，他只做滤波——吉他借了你的嘴。

谁发明的：三个人和一个木偶

1944 年，Alvino Rey 让木偶 Stringy 张嘴，人在幕后吹管。1964 年 Pete Drake 的钢吉他在唱片里说话。1969 年 Kustom 的 The Bag 是第一台量产，30 瓦驱动，挎包像一只皮水囊。1971 年 Bob Heil 为 Joe Walsh 的巡演做了 250 瓦版本。Forbes 说同样的思路更早被注册成人工喉——一件让失去声带的人重新发声的器械。乐器史向医学借了一根管子。

一份圣诞礼物

据说 Frampton 关起门练了两周。难处全在嘴上：含着管子还要把字唱清楚。1975 年《Frampton Comes Alive!》之后，他几乎成了这件东西的同义词，有人干脆叫它 framptone。1988 年 Heil 把制造权卖给 Dunlop，规格没改，一直做到今天。公司会消失，规格留了下来。

机器嗓子的两条路

Kraftwerk 的机器嗓子用电，走的是声码器的滤波器组；Zapp 的 Roger Troutman 用嘴，走的是 talk box 的管子。《More Bounce to the Ounce》之后，这条说话声一路传到 G-funk 和 T-Pain。Pink Floyd 的《Pigs》、Bon Jovi 的《Livin' on a Prayer》里也都是它。塑料管加一只喇叭单元，谁都能攒一台。

以后再听见那种像人又不像人的嗓子，先分辨一件事：声音是从电路里出来的，还是从一张嘴里出来的。

事实来源

  • 主线：滤波发生在嘴里（本页最该记住的一条） —— 「talk box 是一种效果器，允许音乐家通过改变嘴的形状来修改乐器的声音」；「嘴的形状改变谐波含量，其方式与说话时影响声带产生的谐波含量相同」；「这种 shaping 过的声音从演奏者口中出来，进入麦克风时，听到的是乐器/人声的混合体」； 对照 vocoder 条——滤波的位置是两者的分水岭：vocoder 的滤波发生在滤波器组（电子）里，talk box 的滤波发生在口腔（身体）里。talk box 是电子时代最「身体」的效果器
  • 发明争议三方（其他条目「名与实」谱系又一条） —— 「Pete Drake，纳什维尔的 pedal steel 乐手，在 1964 年专辑 Forever 上使用 talk box，后来被称为他的『会说话的钢吉他』（8 英寸纸盆喇叭接一根管）」；「Kustom Electronics 的『The Bag』是第一台量产的 talk box（1969，30W driver，挎在肩上的装饰包像皮水囊——Iron Butterfly/Steppenwolf/Steppenwolf）——Doug Forbes 声称设计，并说同一概念曾被专利为人工喉」；「Bob Heil 声称发明了 talk box——1971 年为 Joe Walsh 的 Barnstorm 巡演开发（250W JBL driver + hi-pass filter）」； 更早的幽灵：1944 年 Alvino Rey 用早期版本录制《St. Louis Blues》——木偶『Stringy』张嘴，人躲在旁边吹管——talk box 的祖先是木偶戏 + 医疗器械（人工喉）
  • Frampton 神话与 Heil 的传承 —— 「1973 年 Heil 把他的 talk box 当圣诞礼物送给 Peter Frampton（100W 手工玻璃纤维版）」；「Frampton 在专辑 Frampton Comes Alive! 上大量使用——由于专辑成功、特别是单曲 Show Me the Way 与 Do You Feel Like We Do，Frampton 几乎成了 talk box 的同义词——它甚至被叫作 framptone」；「1988 年 Heil 把制造权卖给 Dunlop Manufacturing——后者按完全相同的规格生产至今」； 对照「乐器比公司活得久」谱系：Heil 卖了规格，规格活了
  • funk 支线：Zapp 与 Roger Troutman —— 「Roger Troutman，funk 乐队 Zapp 的主唱，以使用 talk box 闻名——《More Bounce to the Ounce》」； 西海岸 G-funk 的 talk box 血统（T-Pain · Snoop Dogg）——funk 的「机器嗓子」与 Kraftwerk 的「机器嗓子」走的是两条路：一个用嘴，一个用电
  • 用户谱系（乐器名人堂） —— Joe Walsh《Rocky Mountain Way》（1973）· Jeff Beck《Blow By Blow》· Pink Floyd《Pigs》（1979）· Bon Jovi《Livin' on a Prayer》· Daft Punk（「机器人」形象常由 talk box 演出——眼见耳听都未必为实，对照 vocoder 条）· Foo Fighters（Dave Grohl）
  • DIY 传统 —— 「Ghetto Talkbox：一种 homemade 版本，通常很粗糙」—— 效果器的民间传统：塑料管 + 喇叭 driver，谁都能攒一台（对照 eurorack 的模块民主）
