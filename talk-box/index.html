说话盒

吉他借你的嘴当滤波器 —— 电子时代最身体的效果器

相关

声码器电吉他特雷门琴音色音高

⭐⭐ 主线：滤波发生在嘴里

「talk box 是一种效果器，允许音乐家通过改变嘴的形状来修改乐器的声音」；「嘴的形状改变谐波含量，其方式与说话时影响声带产生的谐波含量相同」.

⭐⭐ 全站「身体作为乐器」谱系的电子成员：口弦靠嘴的共鸣 · 喉雕把喉咙当共鸣腔 · 约德尔在真声假声间换挡——talk box 把这条线接进了电的时代：嘴不发声，嘴滤波。 吉他不用声带，借你的嘴当滤波器。

HS 分类归属
HS 分类电鸣系统的效果端（不独立发声——寄生在音源上）· 嘴 = 可变滤波器（共振峰）
出身⭐⭐ 发明争议三方：Drake 1964（会说话的钢吉他）· Forbes/Kustom 1969（The Bag 量产）· Heil 1971（250W JBL）——幽灵在 1944（Alvino Rey 的木偶 Stringy）
八音注八音之外——嘴本身就是滤波器：这是全站唯一一件把演奏者的身体当作电路元件的效果器

⭐⭐ 原理：一根管子，三段的旅程

段发生什么
① 放大器吉他（或键盘）的 amp 输出被导入踏板
② 踏板盒内的 horn driver（喇叭驱动器——取掉号筒的喇叭单元）发声，经气密连接进入塑料管；脚踏开关在「talk box 喇叭」与「普通音箱」间切换
③ 嘴里管子另一端贴在麦克风旁、伸到嘴边——声音被送进演奏者的口腔，嘴的形状（唇/舌/腭/齿）就是可变滤波器
④ 麦克风被「shaped」过的声音从嘴里出来，进入麦克风——听到的是乐器/人声的混合体

⭐⭐ 「mouth words，结果是听起来像乐器在说话」——这是全站唯一一件 不插电也能响的「电声乐器」：管子含在嘴里，吉他停下，嘴还在塑造余响。

⭐⭐ 一个用嘴，一个用电——talk box 的「机器嗓子」是借来的肉身。

⭐⭐ 发明争议：三方顶嘴，一个木偶

⭐⭐ 1944 · Alvino Rey 的木偶：「用早期版本录制《St. Louis Blues》—— 与一个叫『Stringy』的木偶」——木偶张嘴，人躲在旁边吹管——talk box 的祖先是木偶戏。 （对照全站计划外发明谱系：「会说话的木偶」比「会说话的吉他」早了二十年。）

说法年代物证
Pete Drake1964专辑《Forever》「会说话的钢吉他」——8 英寸纸盆喇叭接一根管
Doug Forbes / Kustom1969「The Bag」——第一台量产，30W driver，挎包像皮水囊
Bob Heil1971为 Joe Walsh 巡演开发——250W JBL + hi-pass filter

⭐⭐ Doug Forbes 说同一概念曾被专利为「人工喉」——⭐⭐ talk box 的直系祖先是医疗器械：让失去声带的人重新「说话」的管子。乐器史向医学借了一件东西，然后让吉他说了话。（对照全站「名与实」：saer 的名与实错位、合成器一词 1929 年就有乐器—— talk box 的「名」有三个人抢，「实」可能谁都不属于。）

⭐⭐ Frampton 神话：一个圣诞礼物与一个十年

「1973 年，Heil 把他的 talk box 当圣诞礼物送给 Peter Frampton—— 一个 100W 手工玻璃纤维版」；「由于 Frampton Comes Alive! 的成功、特别是单曲 Show Me the Way， Frampton 几乎成了 talk box 的同义词」——它甚至被叫作 framptone.

⭐⭐ 「传闻他闭关两周才掌握」——对照 LinnDrum 的 quantize/swing： 一个「沮丧→发明」，一个「练习→封神」。 talk box 的难全在嘴上：管子含住还能唱清楚，是嘴的极限运动。

⭐⭐ 1988 年 Heil 把制造权卖给 Dunlop——「按完全相同的规格生产至今」。 对照全站公司史（Moog 卖公司 · Sequential 破产 · Prophet 回购）： Heil 卖了规格，规格活了——乐器比公司活得久的又一写法。

⭐ 另一条支线：funk 的机器嗓子

⭐⭐ Roger Troutman（Zapp 主唱）以使用 talk box 闻名——《More Bounce to the Ounce》—— 西海岸 G-funk 的血统（T-Pain · Snoop Dogg）从这里开始。 ⭐⭐ 两条「机器嗓子」的路线：Kraftwerk 的机器嗓子用电（vocoder 的滤波器组）， Zapp 的机器嗓子用嘴（talk box 的管子）——同一个人机合一的目标，一半走电子，一半走肉身。

另有 Pink Floyd《Pigs》（Gilmour 1979）· Bon Jovi《Livin' on a Prayer》· Foo Fighters（Dave Grohl）；⭐ Daft Punk 的「机器人」形象常由 talk box 演出—— 眼见耳听都未必为实（对照 vocoder 条）；⭐ 「Ghetto Talkbox」——homemade 版本，塑料管 + 喇叭 driver 谁都能攒一台（效果器的民间民主）。

事实来源

  • ⭐⭐ 主线：滤波发生在嘴里（本页最该记住的一条） —— 「talk box 是一种效果器，允许音乐家通过改变嘴的形状来修改乐器的声音」；「嘴的形状改变谐波含量，其方式与说话时影响声带产生的谐波含量相同」；「这种 shaping 过的声音从演奏者口中出来，进入麦克风时，听到的是乐器/人声的混合体」；⭐⭐ 对照 vocoder 条——滤波的位置是两者的分水岭：vocoder 的滤波发生在滤波器组（电子）里，talk box 的滤波发生在口腔（身体）里。talk box 是电子时代最「身体」的效果器
  • ⭐⭐ 发明争议三方（全站「名与实」谱系又一条） —— 「Pete Drake，纳什维尔的 pedal steel 乐手，在 1964 年专辑 Forever 上使用 talk box，后来被称为他的『会说话的钢吉他』（8 英寸纸盆喇叭接一根管）」；「Kustom Electronics 的『The Bag』是第一台量产的 talk box（1969，30W driver，挎在肩上的装饰包像皮水囊——Iron Butterfly/Steppenwolf/Steppenwolf）——Doug Forbes 声称设计，并说同一概念曾被专利为人工喉」；「Bob Heil 声称发明了 talk box——1971 年为 Joe Walsh 的 Barnstorm 巡演开发（250W JBL driver + hi-pass filter）」；⭐⭐ 更早的幽灵：1944 年 Alvino Rey 用早期版本录制《St. Louis Blues》——木偶『Stringy』张嘴，人躲在旁边吹管——talk box 的祖先是木偶戏 + 医疗器械（人工喉）
  • ⭐⭐ Frampton 神话与 Heil 的传承 —— 「1973 年 Heil 把他的 talk box 当圣诞礼物送给 Peter Frampton（100W 手工玻璃纤维版）」；「Frampton 在专辑 Frampton Comes Alive! 上大量使用——由于专辑成功、特别是单曲 Show Me the Way 与 Do You Feel Like We Do，Frampton 几乎成了 talk box 的同义词——它甚至被叫作 framptone」；「1988 年 Heil 把制造权卖给 Dunlop Manufacturing——后者按完全相同的规格生产至今」；⭐⭐ 对照全站「乐器比公司活得久」谱系：Heil 卖了规格，规格活了
  • ⭐⭐ funk 支线：Zapp 与 Roger Troutman —— 「Roger Troutman，funk 乐队 Zapp 的主唱，以使用 talk box 闻名——《More Bounce to the Ounce》」；⭐ 西海岸 G-funk 的 talk box 血统（T-Pain · Snoop Dogg）——funk 的「机器嗓子」与 Kraftwerk 的「机器嗓子」走的是两条路：一个用嘴，一个用电
  • ⭐ 用户谱系（乐器名人堂） —— Joe Walsh《Rocky Mountain Way》（1973）· Jeff Beck《Blow By Blow》· Pink Floyd《Pigs》（1979）· Bon Jovi《Livin' on a Prayer》· Daft Punk（「机器人」形象常由 talk box 演出——眼见耳听都未必为实，对照 vocoder 条）· Foo Fighters（Dave Grohl）
  • ⭐ DIY 传统 —— 「Ghetto Talkbox：一种 homemade 版本，通常很粗糙」——⭐ 效果器的民间传统：塑料管 + 喇叭 driver，谁都能攒一台（对照 eurorack 的模块民主）
